# The NVIDIA GPU Family Tree — Pascal to Blackwell

A guided tour of every recent NVIDIA GPU family — Pascal, Volta, Turing, Ampere, Ada Lovelace, Hopper, Blackwell — what changed, when each landed, and why each generation reshaped LLM training and serving. Includes an interactive family explorer.

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
